# Task 03: Dashboard statusu

## Cel

Pokazać bieżący stan urządzenia w czytelnym panelu.

## Zakres

- online/offline;
- nazwa;
- model;
- aplikacja;
- standby;
- active input;
- głośność;
- mute;
- status mediów, jeśli dostępny;
- polling AJAX;
- obsługa natywnych aplikacji bez namespace.

## Kryteria akceptacji

- dashboard nie zawiesza się przy wyłączonym urządzeniu;
- błędy sieciowe są prezentowane bez tracebacka;
- odświeżanie nie tworzy niekontrolowanej liczby połączeń.
