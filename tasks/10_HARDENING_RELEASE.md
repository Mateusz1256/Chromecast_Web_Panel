# Task 10: Hardening i wydanie 1.0

## Cel

Domknąć projekt do stabilnego wydania.

## Zakres

- pełny przegląd bezpieczeństwa;
- testy regresji;
- backup i restore;
- migracje ustawień;
- eksport diagnostyczny bez sekretów;
- dokumentacja użytkownika;
- dokumentacja developera;
- release checklist;
- wersja `1.0.0`.

## Kryteria akceptacji

- wszystkie testy przechodzą;
- instalacja od zera jest udokumentowana i zweryfikowana;
- brak znanych krytycznych błędów;
- zależności i licencje są udokumentowane.
