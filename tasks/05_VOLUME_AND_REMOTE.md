# Task 05: Głośność i podstawowy pilot

## Cel

Dodać podstawowe sterowanie.

## Zakres

- suwak głośności;
- limit maksymalnej głośności;
- mute/unmute;
- play/pause/stop;
- seek, gdy wspierany;
- przyciski blokowane, gdy komenda nie jest wspierana;
- rate limit.

## Kryteria akceptacji

- backend wymusza limit, niezależnie od frontendu;
- brak ustawienia 100% przez przypadek;
- status po komendzie jest odświeżany.
